# VORBY — сайт-визитка

VORBY — придуманное название, созвучное с «воробей». Сайт на чистых HTML, CSS и JavaScript, без сборки, внешних библиотек, сервера, базы данных и регистрации. SEO-услуг и категории Telegram-ботов нет.

## Файлы

- `dist/index.html` — разметка и тексты сайта.
- `dist/styles.css` — оформление, анимации и мобильная версия.
- `dist/script.js` — цены, калькулятор, контакты и интерактивность.
- `dist/rubik.js` — объёмный кубик Рубика и анимация сборки.
- `PRICING.md` — объяснение стартового прайса и ссылки на похожие предложения.
- `preview.cjs` — необязательный локальный сервер для просмотра; на хостинг не нужен.

## Как открыть

Откройте `dist/index.html` в браузере двойным щелчком. Сайт работает даже без интернета. Если браузер запрещает копирование в буфер для локальных файлов, откроется окно с расчётом для ручного копирования.

Если установлен Node.js, можно запустить `node preview.cjs` из папки проекта и открыть `http://127.0.0.1:4173`. Остановка сервера — Ctrl+C.

## Что заменить перед публикацией

1. В начале `dist/script.js` найдите `SITE_CONFIG`. Укажите ваш Telegram в `telegramUsername` без символа `@`. Пока он пуст, кнопка объясняет, что контакт ещё не добавлен; никаких сообщений и заявок на сервер не отправляется.
2. В `projects` установлен рекомендуемый стартовый прайс: сайт 6 000 ₽, баннер 1 000 ₽, доработки 1 000 ₽. Подключение домена +500 ₽, то есть сайт с доменом даёт 6 500 ₽. Обоснование и ограничения — в `PRICING.md`. Цены легко изменить; итоговую сумму всё равно согласовывайте по заданию клиента.
3. Проверьте объём услуг и описания: они намеренно ограничены количеством блоков, изображений и правок. Подставьте свои условия.
4. Карточки «Личный взгляд», «Форма и смысл» и «Место для своих» — демонстрационные мини-макеты прямо в HTML. Это не реальные заказы и не отдельные готовые сайты. Замените их своими работами, когда они появятся.
5. Если хотите другое название, измените `brand` в конфигурации и статические надписи VORBY в HTML, чтобы название совпадало и при отключённом JavaScript. Начальный текст цен в HTML тоже можно обновить; при включённом JavaScript все суммы берутся из конфигурации.

## Калькулятор

Выберите «Сайт», «Дизайн» или «Доработки», затем отметьте дополнения. К базовой цене прибавляются только выбранные услуги. Выбор для каждого направления сохраняется в памяти открытой страницы при переключении; после перезагрузки сбрасывается. Кнопка «Сбросить выбор» очищает все направления и возвращает базовый сайт. На телефоне во время выбора дополнений показывается компактная строка с суммой внизу экрана.

Публикация, адаптация под телефон, кнопки связи, favicon и исходные файлы включены в новый сайт. Цена домена у регистратора не включена в стоимость подключения. Калькулятор показывает ориентир; окончательные условия согласовываются с клиентом.

«Скопировать расчёт» создаёт текст с перечислением услуг. После настройки Telegram кнопка «Обсудить этот проект» открывает ваш чат с подготовленным текстом. Посетитель сам нажимает отправку. Если приложение Telegram не подставило текст, его можно вставить кнопкой копирования.

## Публикация

На статический хостинг загружайте только содержимое `dist`: `index.html`, `styles.css`, `script.js`, `rubik.js`. Они должны лежать рядом. Используются относительные ссылки, поэтому сайт можно размещать и в подпапке проекта. Сборка и npm не нужны.

Если выбран хостинг с публикацией из корня репозитория, загрузите четыре файла из `dist` в его корень. Папку `dist`, `preview.cjs` и этот README переносить не требуется. Для подключения своего домена используйте инструкции выбранного хостинга и регистратора.

## Оформление и доступность

Цвета меняются через переменные в начале `styles.css`. Адаптация предусмотрена для телефонов, планшетов и компьютеров. Есть мобильное меню, клавиатурное управление, видимый фокус, раскрывающиеся ответы, анимации появления, бегущая строка, смена слова в первом экране и объёмный кубик Рубика.

Кубик состоит из 26 отдельных элементов и 54 цветных накладок. WebGL рисует корпус с фасками, освещением и перспективой. Слои поворачиваются на 90 градусов, затем обратная последовательность действительно возвращает кубик в собранное состояние. Цикл повторяется. Если WebGL недоступен, та же геометрия рисуется через обычный canvas с сортировкой треугольников по глубине. Если отключён JavaScript, остаётся декоративный фон, а весь основной текст сайта виден.

При системном предпочтении уменьшенного движения эффекты отключаются, кубик показывается собранным и неподвижным. Анимация приостанавливается вне экрана и в неактивной вкладке. Код не загружает модели или библиотеки из интернета.

Сайт не хранит личные данные, не использует cookies и не собирает аналитику. Контент виден без JavaScript, но интерактивный калькулятор требует его включения.
